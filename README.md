# Pebble Sense Time
HTC Sense clock replica  with that legendary Flip Clock widget of the noughties when you could find this on both Android and Windows Mobile phones 🤖🪟


## Features
- Large Flip Clock that follows localisation settings. Font can be setin Semi Light and Semi Bold. Minute and hour cards make a really nice flip animation on the minute/hour which you trigger at any time again with a flick of your wrist (both will then flip).
- Location based weather (Open Meteo) with icon, current temperature and (current) location name below the clock.
- On the right side of that the Weekday and Date. These follow the watch language settings (supports: en/fr/de/es/it/nl/pt).

Below that iconic HTC Sense clock widget there was some room left for some old fashioned 'desktop' icons with more useful info:
- Today's high and Low temperature
- Daily Step total
- Daily Sleep total
- Watch battery percentage
- Phone battery percentage (will append ↑ when charging)

Furthermore:
- Five original HTC Sense wallpapers you can set
- Temperatures in C or F setting
- Transparant raindrops overlay when it's rainy weather. On by default, but you can turn it off in settings

Weather by Open Meteo, Location name by https://api.bigdatacloud.net/data/reverse-geocode-client

PS: This watchface is very heavy on memory (due to all the transparencies), so it will sometimes happen that a wallpaper will not load. 
In that case: switch to another face, and then back and it will have loaded. Or turn off the Raindrops layer.
Compression wise there's little else I can do... 🤷
